## 6. 测试过程发现

1. 首轮 PRJ-04 永久停在 `queued`：异步线程在事务提交前读取 Task。已改为 `afterCommit` 后投递，复验通过。
2. 现有数据库 UUID 列使用 `utf8mb4_0900_ai_ci`，静态关联表使用 `general_ci` 会导致外键不兼容。迁移现动态继承 `projects.id` 的 collation。
3. running 取消最初只在整条流水线结束后生效。现通过共享取消标记让 Python 在校正、HSV、熵、主色等步骤边界检查并提前返回，PRJ-18 通过。
4. Docker USTC 镜像站持续在 `python:3.11-slim-bookworm` 元数据查询处返回 EOF。源码已同步；为保证本地重启一致性，已将通过回归的 Python 容器固化为本地同名镜像并重新创建验证。
5. API 镜像已加入 Maven BuildKit 缓存挂载，后续源码改动的构建不再重复下载全部依赖。
6. 模板用例原先使用错误字段名 `regions_json`，且列表/详情只断言 HTTP 200、更新删除依赖 Swagger 人工判断。现已按控制器真实契约改为 `regionsJson`，并加入字段、两个图片端点 MIME、更新持久化及删除后 404 断言。
7. 新增图片端点断言发现 `/api/templates/{id}/image/file` 对相对图片 key 错按进程工作目录解析并返回 404。服务层已统一通过 `storage.base-dir` 安全解析相对 key；修复后返回 `200 image/jpeg`，并经完整回归验证。
8. 模板删除接口的 409 原本由全局拦截器留给调用页面处理，但页面未提供反馈。现模板删除处理器会解析引用数量并显示场景化警告弹窗，UI-09 实测通过。
9. 创建向导第二步原先只把受保护的原图 URL 标成 `ready`，既未调用 align，又因普通 `<img>` 缺少 JWT 而无法显示。现改为同步逐张调用 align、以 Blob URL 展示和下载、失败可真实重试；不创建 Task，也不写回源数据集。UI-10 实测通过。
