## 6. 测试过程发现

1. **JWT 认证 401 错误修复**：`JwtAuthenticationFilter.java` 在所有请求上执行 JWT 验证，即使路径配置了 `permitAll()`，如果 JWT 验证失败或抛出异常，仍会导致 401 错误。
2. **修复方案**：在 `JwtAuthenticationFilter.doFilterInternal()` 中添加路径检查，跳过 `/api/auth/`、`/api/images/`、`/api/tasks/`、`/v3/api-docs/`、`/swagger-ui` 等公开端点的 JWT 验证。
3. **调试日志验证**：在 `JwtAuthenticationFilter` 中添加了详细的调试日志，包括请求路径、Authorization header、提取的 token、用户名以及验证结果。通过后端日志确认 JWT 认证流程正常：
   - 日志显示 `JWT Filter: path=/api/datasets, username=admin`
   - 日志显示 `JWT Filter: Authentication set for user=admin`
   - 验证了 token 正确提取、用户名正确解析、认证成功设置到 SecurityContext
4. **Docker 镜像源配置**：配置了国内 Docker 镜像源（中科大、网易、腾讯云、阿里云），解决 Docker Hub 连接超时问题。
