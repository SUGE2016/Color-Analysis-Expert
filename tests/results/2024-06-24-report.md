## 6. 测试过程发现

> 测试配置、脚本、契约、文档问题（非产品代码缺陷）。

1. 发现 `tests/fixtures/images/` 目录缺少测试图片文件，导致多个用例无法执行（已补充）
2. 发现中文字符在 API 响应中显示为乱码（如"测试分组"显示为"?????"），需要检查字符编码配置
3. 前端环境变量 `REACT_APP_UPLOAD_BASE_URL` 需要包含 `/api` 后缀（已在本次修复）
4. 前端 API 导出缺少 `API_BASE_URL`（已在本次修复）
5. 前端多处使用 `API_BASE_URL.replace()` 需要添加默认值防止 undefined 错误（已在本次修复）
6. 图像矫正算法 API 需要特定的图像质量才能检测到角点，否则返回 422 错误
